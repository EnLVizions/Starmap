# Pythagoras Star Map

Interactive static site for the Pythagoras interstellar star map: known star systems within 50 light-years, ranked as destinations by distance, planet habitability, and the interstellar medium along the route.

Data comes from the NASA Exoplanet Archive (USA), ESA Gaia DR3 (Europe), SIMBAD/CDS (France), and other catalogues listed on the [sources](docs/sources.html) page. This is design and reference data, not flight-certified software or navigation.

Open `index.html` for the maps, system profiles, and downloads. The site is published with GitHub Pages from the repository root.
